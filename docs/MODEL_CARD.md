# Model card: fused crop risk classifier

## Overview

| Field | Value |
| --- | --- |
| Version | 1.0.0 |
| Artifact | `artifacts/risk_model.joblib` (joblib, ~0.6 MB) |
| Algorithm | `sklearn.ensemble.HistGradientBoostingClassifier` |
| Task | 3-class zone risk: `healthy`, `moderate`, `high` |
| Inputs | 17 numeric features (7 spectral, 3 temporal, 7 climate) |
| Outputs | Class probabilities, expected risk in `[0, 1]`, risk level |
| Training code | `cropmon.models.fusion.train_risk_model` |
| Reproduce | `python scripts/train_model.py` with `CROPMON_SEED=42` |

## Intended use

Rank management zones for scouting and irrigation decisions, and trigger SMS alerts when
a zone crosses a risk threshold. Designed for agronomists, field technicians, and
researchers working with multispectral imagery plus in-field sensors.

**Not** intended for autonomous spraying decisions, pesticide dosing, or regulatory
reporting. Every alert should be confirmed by a human in the field.

## Training data

Generated by `cropmon.data.synthetic`:

* 96×96 px, 12-band reflectance cube from a leaf/soil mixing model, with spatial stress
  blobs, a disease map, and per-pixel noise.
* 14 days of hourly weather: diurnal temperature, humidity coupled to temperature,
  Poisson rainfall, and a root-zone water balance (~5 mm/day ET over 300 mm depth).
* 12 weeks of per-zone NDVI with declining zones and an injected stress event.
* 256 zones, each with a microclimate offset.

Labels come from a composite agronomic score
`0.35·canopy_deficit + 0.30·disease_pressure + 0.20·water_deficit + 0.15·latent_disease`,
thresholded at 0.42 and 0.58, then flipped with 8 % probability to emulate imperfect
scouting notes.

## Evaluation

Stratified 70/30 split, seed 42, 179 train / 77 test zones.

| Metric | Value |
| --- | --- |
| Accuracy | 0.883 |
| Macro F1 | 0.857 |
| ROC AUC (OvR, macro) | 0.937 |

Confusion matrix (rows = actual, columns = predicted):

|  | healthy | moderate | high |
| --- | --- | --- | --- |
| healthy | 37 | 3 | 0 |
| moderate | 3 | 25 | 1 |
| high | 0 | 2 | 6 |

Permutation importance (accuracy drop, 5 repeats): PSRI 0.338, NDVI 0.039,
soil moisture 0.029, leaf-wetness fraction 0.016, GNDVI 0.013.

## Interpretation

The metrics measure **how well the model reproduces the simulator's agronomic model**.
Because labels are generated from a formula that partly uses the same observables, the
scores are an upper bound, not a field-performance estimate. The 8 % label noise keeps
them from being trivially perfect, but do not quote 0.88 as an accuracy claim for real
fields.

PSRI dominating is expected: it is the most direct senescence signal in the band set and
the label weights canopy deficit heavily. Climate features contribute less because the
simulator's per-zone microclimate offsets are small.

## Limitations

* No real imagery, no atmospheric correction, no cloud masking.
* No pest counts or trap data; "pest risk" is inferred from weather only.
* No soil texture, pH, or nutrient data.
* No yield calibration, so risk levels are relative within a field, not absolute losses.
* Single-season simulation; no crop rotation or phenology stage model.
* Zone size is fixed by `CROPMON_ZONE_ROWS/COLS`, not by agronomic management zones.

## Ethical and operational notes

* Alerts are decision support. Misclassifying a healthy zone as high risk wastes input;
  the reverse loses yield. Both are cheaper than unverified spraying.
* The simulator can encode convenient assumptions. Validate against scouting records
  before trusting any threshold.
* No personal data is required to run the platform. SMS recipients are supplied at
  runtime via `ALERT_RECIPIENT`, never stored.

## Retraining

```bash
CROPMON_SEED=123 python scripts/train_model.py   # new snapshot, same interfaces
```

To train on real data, implement a loader that produces the same 17 columns and the
`risk_class` target, then call `train_risk_model`. Keep `FEATURE_COLUMNS` stable or bump
`MODEL_VERSION` in `cropmon/models/fusion.py`.
