# Original MATLAB prototype output (pre-fix)

These are the figures the SIH25099 MATLAB prototype produced, kept unchanged as
evidence. **Do not read them as current results.** The corrected equivalents are
`docs/figures/index_panel.png` (generated by `cropmon.viz.index_panel`) and
`matlab/index_panel.m` (corrected MATLAB).

The seven montages are successive states of the same figure canvas, exported at
2400 x 1018 with the unused subplots left black. Upload order is preserved in the
file prefix.

## Defects visible in these files

1. **EVI is off by three orders of magnitude.** The colourbar in
   `legacy_01_full_stack_7panel.png` runs -5000..1000 and the map is a flat
   orange block. Raw 16-bit digital numbers were fed in and the `+1` (L) term was
   missing from the denominator. With reflectance in 0-1 and L = 1, EVI stays
   inside [-1, 1]; the corrected panel plots it on 0..1.1.
2. **The class map is a single class.** The `ClassifiedMap` colourbar spans 2..3
   over a solid dark red field, and the accompanying `CropHealthSummary.csv`
   records 21024 of 21025 pixels as `PestRisk`, one `Stressed`, zero `Healthy`.
   The if/elseif chain fell through to its last branch. Archived alongside these
   figures at `legacy/matlab_output/CropHealthSummary.csv`.
3. **The index maps carry no field structure.** All five vegetation indices are
   salt-and-pepper noise, and NDVI sits largely below zero, which no vegetated
   field does. The input cube was effectively uncorrelated random reflectance, so
   these panels cannot be read agronomically.

The corrected pipeline classifies the same 9216-pixel field as 5517 healthy /
3035 moderate / 664 stressed, with contiguous stress patches around the
simulated disease foci rather than per-pixel noise.
